# Ecoserv Time In (test)

The phone page for the Ecoserv Time In pilot. Workers open it on their phone, take a live selfie,
and send their time in or time out. This repo holds only the page: no names, PINs, photos or
times are stored here. Everything is saved to the company's Google Sheet and Drive through a
Google Apps Script web app, and each worker needs their Employee No and PIN the first time.
